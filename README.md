# لامين لإدارة وتنظيم المدارس — Adreemk

تطبيق Flutter Android متصل بـ Supabase ومصمم للعمل بأقل عدد ممكن من الخطوات.

## الحالة
الإصدار البرمجي الحالي: 2.0.3+15. فحوصات CI على commit `7cadb0c3a94867ddffa2d5bb71101da36f3a854a` ناجحة. حالة الاعتماد التجاري: **مرشح إصدار، وليس إطلاقاً تجارياً معتمداً**؛ ما زالت اختبارات الهاتف والتوقيع التجاري واعتماد الوثائق مطلوبة.

## الوظائف
- تسجيل الدخول والجلسة المستمرة.
- لوحة مدرسية مختصرة.
- إضافة وبحث الطلاب.
- WhatsApp مباشر لولي الأمر.
- الحضور: السجل غير المسجل يظهر بوضوح، وتُحفظ دقائق التأخير ضمن سجل المتأخر.
- مزامنة العمليات المحلية: عدّاد للعمليات المعلقة، وإعادة محاولة يدوية، ورسالة توضح نوع العملية التي تعذر إرسالها.
- المالية: لا تظهر أسماء الطلبة أو حساباتهم حتى البحث بالاسم.
- تسجيل الدفعات والمصروفات.
- إدارة المعلمين.
- قاعدة بيانات متعددة المدارس مع RLS.
- جداول السنوات الدراسية والفصول وأولياء الأمور والحضور والمصروفات وإشعارات WhatsApp.

## حماية البيانات المحلية
- تشفير مخابئ بيانات المدرسة والطلاب وأولياء الأمور والرسوم والمدفوعات والحضور عبر التخزين الآمن للنظام.
- تشفير قائمة العمليات المؤجلة ومعرّفات المزامنة واسم المستخدم المحفوظ.
- تشفير ملفات النسخ الاحتياطية المحلية باستخدام AES-256-GCM مع مفتاح منفصل محفوظ في التخزين الآمن للنظام.
- إنشاء النسخة المحلية من البيانات المخزنة مشفراً على الجهاز وقائمة التعديلات المعلقة دون حاجة إلى الاتصال بـ Supabase؛ وهي لقطة من البيانات الموجودة محلياً وليست تصديراً كاملاً جديداً من الخادم.
- استعادة لقطة التخزين المحلي إلى الجهاز مع التحقق من تطابق حساب المستخدم والمدرسة.
- ترحيل النسخ المحلية القديمة إلى ملفات مشفرة بعد التحقق من سلامتها، ثم إزالة النسخ النصية القديمة.

## البنية
- Flutter Android
- Supabase Auth + PostgreSQL + RLS
- GitHub Actions لبناء APK
