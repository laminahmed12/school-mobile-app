# بوابة لامين للحاسوب

واجهة ويب عربية RTL مضافة إلى المستودع نفسه، وتستخدم مشروع Supabase الحالي بدل إنشاء قاعدة مالية ثانية.

## الاستضافة المعتمدة
- **الاستضافة الأساسية والإنتاجية المعتمدة: Cloudflare Pages**.
- الرابط الرسمي للبوابة: https://lamin-school-portal.pages.dev
- مشروع Cloudflare Pages: `lamin-school-portal`.
- المستودع: `laminahmed12/school-mobile-app`.
- فرع الإنتاج: `fix/lamin-portal-crud-offline-20261030`.
- جذر الموقع: `web/`، ومجلد الإخراج: `/`، دون أمر بناء.
- النشر التلقائي مربوط بفرع الإنتاج أعلاه.
- Vercel ليس عنوان التشغيل المعتمد. يُترك المشروع القديم دون حذف كنسخة احتياطية مؤقتة، ولا تُحوّل إليه المستخدمين.
- لا تعتمد أي نطاق مخصص أو تغيّر DNS دون التحقق من ملكية النطاق وإعداداته.

## الحالة والحدود
- تسجيل الدخول عبر Edge Function الحالية `auth-login` ثم جلسة Supabase.
- لوحة ملخص وقوائم للطلاب والمعلمين والصفوف والمبالغ المالية، مع الاعتماد على RLS في قاعدة البيانات.
- تصدير CSV لقوائم الطلاب والمعلمين والحضور والرسوم وسجل التدقيق.
- تقرير Excel متعدد الأوراق وتنسيق طباعة مناسب لحفظ التقارير بصيغة PDF من المتصفح.
- نسخة JSON عبر RPC الحالية `export_backup`، مع التحقق من أن `school_filter` يطابق المدرسة النشطة.
- فحص ملف النسخة قبل الاستعادة، وطلب تأكيد نصي، ثم استدعاء RPC `restore_backup` الحالية.
- لا تُنفّذ الواجهة أي ترحيل قاعدة بيانات ولا تغيّر إعدادات الإنتاج.
- نجاح نشر الملفات على Cloudflare لا يُعد وحده اعتمادًا وظيفيًا؛ يلزم اختبار الدخول والأدوار والبيانات والتقارير والنسخ والاستعادة على الرابط الأساسي.

## تشغيل محلي
قدّم مجلد `web/` عبر خادم ملفات ثابت يدعم HTTPS في النشر. يستخدم `app.js` المفتاح publishable المخصص للعميل؛ لا تضع مفاتيح service-role أو أسرارًا في ملفات الويب. المصادقة والتفويض النهائيان مسؤولية Supabase Edge Functions وRLS وإجراءات RPC.

## نقاط التحقق التشغيلية
1. اختبار تسجيل الدخول والخروج والجلسة وتحديث الصفحة.
2. اختبار أدوار owner وadmin والحساب غير الإداري والتحقق من RLS.
3. اختبار قوائم الطلاب والمعلمين والموظفين والإضافة والتعديل والأرشفة والاستعادة.
4. التحقق من دقة المجاميع المالية والفترات والسنة الدراسية.
5. اختبار تصدير CSV وExcel/PDF والنسخ JSON واستعادة نسخة صحيحة ورفض ملف مدرسة أخرى أو ملف تالف في بيئة تجريبية.
6. التحقق من عمل الخدمة دون اتصال للملفات المخزنة مؤقتًا، وعدم عرض بيانات مدرسة أو حساب آخر.

## النشر
- Cloudflare Pages متصل مباشرة بفرع الإنتاج المحدد ومجلد `web/`.
- مسارات تغييرات النشر تُحسب نسبةً إلى جذر المشروع؛ راجع سجل Cloudflare للتأكد من أن آخر deployment لم يُتخطَّ بسبب path filters.
- لا تحذف نسخة Vercel القديمة حاليًا؛ إبقاؤها احتياطية لا يجعلها الاستضافة المعتمدة.
